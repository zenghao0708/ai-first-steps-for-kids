# 第 1 章漫画内容分析

## 核心信息

孩子可以通过“输入—处理—输出”观察生活中的智能工具，同时记住自动设备不一定使用 AI，AI 的判断也可能出错。

## 目标读者

- 主要读者：8—10 岁、没有技术基础的小学三年级学生。
- 共读者：家长和教师，需要插画能支持提问与课堂讨论。
- 阅读需求：先看到熟悉场景和小冲突，再接受一个简短术语；不能依赖小字号说明。

## 阅读价值

- 知识价值：认识 AI、输入、处理、输出以及“判断可能错误”。
- 情感价值：把抽象技术变成侦探任务，鼓励好奇而不是崇拜机器。
- 实践价值：孩子能在家里或学校观察自动设备，并诚实记录“还不知道”。

## 叙事线

1. 小问把相册搜索当成魔法。
2. 狗形云被错认，朵朵发现反例。
3. 三个盒子把神秘过程拆成可观察步骤。
4. 六种设备被放上侦探台，孩子学会找证据而不是凭外表贴标签。

## 视觉机会

| 概念 | 视觉表达 |
| --- | --- |
| 判断错误 | 狗照片中混入一朵狗形云 |
| 输入—处理—输出 | 三个独立区域和清晰折线箭头 |
| 自动不等于 AI | 六个生活设备的侦探比较台 |
| 证据不足 | 小问举起“？”牌，保留后期文字区域 |

## 适配规则

- 保留：狗形云、三盒流程、六种设备和“还不知道”的结论。
- 简化：不在漫画里解释算法、模型类型或神经网络。
- 扩展：角色对错误结果的表情反应，让孩子先笑再思考。
- 避免：把机器人画成人类心智、把处理过程画成魔法火花、在图片模型中生成长段中文。
