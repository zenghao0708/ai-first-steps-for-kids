# 家长与教师指南

## 教学定位

五年级分册从“知道数据影响模型”进入“理解表示、模型和应用链”。孩子不需要推导矩阵和微积分，但应能用图、比例和中间结果说明：输入怎样变成向量，模型怎样根据误差调整，RAG 怎样先检索再生成，评测为什么要分开误报与漏报。

技术密度提高时，建议每次只保留一条主链。讲注意力不同时讲训练集全部细节；讲 RAG 时先固定一个小资料库；讲指标时先用自然语言说分母，再计算比例。

## 推荐课时

每章 1—2 课时。若只有八课时，优先选择第 2、3、4、5、7、9、10、12 章，形成“建模—表示—训练—注意力—检索—结构—评测—项目”主线。

阶段作品包括向量邻居图、权重调整日志、人工 RAG 链路图、混淆表和知识助手评测板。评价证据链，不以是否调用真实 API 为标准。

## 数学边界

可以使用坐标、分数、百分数和固定筹码。向量先用二维再说明真实系统高维；梯度只解释局部调整方向；注意力用 Q/K/V 直觉但强调真实计算是矩阵变换；精确率与召回率必须让孩子说清“谁除以谁”。

若孩子希望进一步学习，可提供可选编程实验，但不把 Python 环境配置变成全班门槛。代码示例需要固定依赖、虚构数据、可重复输出和解释性注释。

## 在线服务与数据

儿童不应独立注册模型或向量数据库。成人演示前检查当前年龄限制、区域政策、学校规定、输入保存、训练用途和删除能力。

RAG 演示只使用公开或虚构资料。不要上传学生作品、内部通知、真实课表、联系方式、人脸与声音。嵌入仍来源于原文，不能因为变成数字就忽略隐私。

## 事实与引用

要求回答中的日期、名称、数字逐项打开原始来源核对。模型生成的引用可能不存在，RAG 引用可能存在却不支持句子。让孩子练习“未找到证据”与“资料冲突”，比追求每题都有答案更重要。

## 评价量规

| 维度 | 可观察证据 |
| --- | --- |
| 表示理解 | 能说明向量保留什么、遗漏什么 |
| 机制理解 | 能画出训练、注意力或 RAG 的中间步骤 |
| 实验设计 | 保留对照、测试集和失败样本 |
| 量化能力 | 能解释指标分母与现实错误代价 |
| 来源意识 | 回到原文核对，不把引用当装饰 |
| 系统意识 | 区分资料、检索、模型、校验与人工 |
| 责任表达 | 说明工具贡献、限制和拒答条件 |

## 安全讨论

深度合成案例只练暂停、换渠道与求助，不展示可复制攻击步骤。不要让孩子模仿教师或同学声音。对作业使用 AI 的判断依据过程记录和校规，不依赖单一“AI 检测器”。

## 读者试测

建议观察孩子能否区分“向量相近”和“事实相同”、能否说出 RAG 至少两个失败点、能否从混淆表指出误报与漏报。若插图被误解为真实网络内部截图，应强化“示意图”边界。
