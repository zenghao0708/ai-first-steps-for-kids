# 8—10 岁读者试读方案

## 目标

验证孩子是否看得懂关键概念、能否从插图获得帮助、是否会把 AI 拟人化，以及活动说明是否安全可执行。试读不是考试孩子，而是测试书稿。

## 参与与隐私

- 建议 3—5 名小学三至四年级读者，取得监护人明确同意。
- 不记录真实姓名、学校、联系方式、声音、视频和完整作业。
- 观察表只使用“读者 A/B/C”和年龄段。
- 不要求孩子登录在线 AI，不展示诈骗实物或不适龄内容。

## 单次流程

每名读者选择一章，控制在 25—35 分钟。

1. 自主阅读漫画开场和两小节。
2. 用自己的话解释一个新词。
3. 遮住正文，只看插图说出流程。
4. 完成该章任务卡中的一个步骤。
5. 回答“AI 在哪里可能出错”“出错后找谁帮助”。
6. 指出一处难懂、无聊或容易误会的地方。

成人只追问，不提示标准答案。孩子停顿超过 20 秒、反复读三次或解释与原意相反时，记录具体位置。

## 首版通过标准

- 80% 以上试读者能说出本章一个正确核心概念。
- 80% 以上试读者能从流程图按正确顺序说出主要步骤。
- 所有人都知道高风险内容不能只听 AI，并能说出合适的求助对象。
- 没有活动诱导孩子上传个人信息或执行危险动作。
- 同一位置若有两名以上孩子误解，必须改写正文或插图后复测。

## 反馈优先级

1. 可能导致危险、隐私泄露或错误信任的问题。
2. 把 AI 当成人、把流畅当事实的概念误解。
3. 图片中文字、箭头、顺序或图注冲突。
4. 句子过长、术语过密和活动步骤不清。
5. 版面、节奏和趣味性建议。

每次修订记录提交号和复测结果。不要用“孩子喜欢”替代可观察证据。
