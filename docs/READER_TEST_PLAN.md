# 三至六年级读者试读方案

## 目标

验证目标年级能否看懂本册关键概念、从插图获得帮助、完成纸面任务并说出安全边界。试读不是考试孩子，而是测试书稿、图片和活动设计。

## 分层样本

每册建议至少 3 名对应年级读者，并取得监护人明确同意。不要让低年级读者代替高年级样本，也不要只邀请已经参加编程或 AI 课程的孩子。

| 分册 | 重点观察 |
| --- | --- |
| 三年级 | 能否区分输入、处理、输出，并知道 AI 会出错和需要求助 |
| 四年级 | 能否说明数据、特征、规则与测试证据，而不是只说“模型聪明” |
| 五年级 | 能否沿模型、检索、证据、输出链路定位错误 |
| 六年级 | 能否解释系统边界、停止条件、人工责任和暂不发布理由 |

## 隐私与安全

- 不记录真实姓名、学校、联系方式、声音、视频和完整作业。
- 观察表只使用“G4-读者 A”一类编号和年级。
- 不要求孩子登录在线 AI，不上传个人照片、声音、位置或校内资料。
- 所有任务使用书中虚构资料；在线演示由成人控制。
- 发现活动可能诱导真实数据或高风险操作时立即停止试读并修订。

## 单次流程

每名读者选择一章，低年级控制在 25—35 分钟，高年级控制在 35—45 分钟。

1. 自主阅读漫画开场和核心内容。
2. 用自己的话解释一个新词和一个不能这样理解的边界。
3. 遮住正文，只看插图说出流程或比较关系。
4. 完成对应任务卡的关键步骤。
5. 找出一个可能失败的位置，并选择停止、降级、求助或复测。
6. 指出一处难懂、无聊、容易误会或不符合生活经验的地方。

成人只追问，不提示标准答案。孩子停顿超过 20 秒、反复读三次、跳过整幅图或解释与原意相反时，记录具体页、图和原话。

## 分册通过标准

- 80% 以上试读者能说出本章一个正确核心概念和一个适用边界。
- 80% 以上试读者能从图中按正确顺序说明主要步骤或比较维度。
- 所有人都知道高风险结果不能只听 AI，并能说出合适的求助对象。
- 五年级读者能在给定链路中指出证据来自哪一步。
- 六年级读者能为一个失败场景选择停止、降级、回滚或人工接管。
- 没有活动诱导孩子上传个人信息或执行真实高风险动作。

同一年级同一位置若有两名以上孩子误解，必须改写正文或插图后用新读者复测。不要把成人觉得“已经很清楚”当作通过证据。

## 反馈优先级

1. 可能导致危险、隐私泄露或错误信任的问题。
2. 把模型当成人、把流畅当事实、把自动化当责任人的概念误解。
3. 图片中文字、箭头、顺序、图注或正文之间的冲突。
4. 术语密度、长句、任务步骤和年级难度不匹配。
5. 版面、节奏和趣味性建议。

每次修订记录提交号、影响分册和复测结果。“孩子喜欢”可以保留为体验反馈，但不能替代可观察的理解与安全证据。
