# 插画资产说明

## 目录用途

- `source/`：角色表和可编辑源文件。大型 PSD、CLIP 文件默认忽略，只提交轻量预览或开放格式源文件。
- `print/`：印刷版高清图片，当前统一输出 2400×1800 PNG、300 DPI；最终印刷尺寸由排版阶段确认。
- `epub/`：电子书与 GitHub 阅读图片，当前统一输出 2000×1500 高质量 JPEG、sRGB。

`print/` 是可重新生成的本地产物，默认不提交 Git；`epub/` 中的阅读版图片会随书稿提交。漫画工作目录中的页面预览同样默认忽略，只提交角色参考表、分镜和提示词。

## 文件命名

```text
ch01-01-photo-search.png
ch01-02-input-process-output.png
ch01-03-ai-map-activity.png
```

## 质量检查

- 角色外观在全书中一致。
- 中文不直接依赖图片模型生成，优先后期排版。
- 图中箭头不遮挡人物、气泡或文字框，箭头尖端停在边框。
- 每幅图在正文中有明确引用和替代文本。
- 事实图与装饰图分开审查；事实图必须由成人技术审校。
