# 第 2 章漫画内容分析

## 核心信息

机器学习会从许多例子中寻找规律；数据、标签和特征会影响学习结果，必须用没见过的新例子测试。

## 视觉教学任务

1. 用水果分拣误会建立“一个线索不够”的冲突。
2. 把数据、标签、特征、训练和测试放进一个连续可读的卡片流程。
3. 对比只看红苹果与丰富苹果样本，表现数据范围如何改变结果。

## 适配边界

- 不把训练画成机器人读书或人脑发光。
- 不用单条固定规则冒充完整机器学习算法。
- 不出现真实儿童照片、学校名称、品牌或可识别个人数据。
- 图片中的术语标签留空，统一由后期排版加入。
