# 第 4 章漫画内容分析

核心信息：机器首先处理像素数字，再利用图案完成分类、检测或分割；角度、光线、遮挡与背景会改变结果。

两幅图分别承担“水杯并没有消失”的认知冲突，以及“像素—图案—不同视觉任务—困难测试”的机制解释。图中不出现真实儿童照片和身份信息。
